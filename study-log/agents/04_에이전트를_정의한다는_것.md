# Concept

- 역할 계약서(에이전트 파일) 기준 세션 별 인스턴스 생성

# 에이전트 파일

- 위치 별 우선순위(이름이 같으면 상위가 우선)
    - Managed Settings (조직)
    - —agents CLI flag (세션)
    - .claude/agent (프로젝트)
    - ~/.claude/agents/ (사용자 전역)
    - 플러그인 agents (플러그인 활성화 시)
- 구성
    - 프론트매터
        - name, description, model, tools, 선택필드
        - 호출자가 에이전트를 식별하고 호출하는데 필요한 정보
    - 본문
        - 핵심 역할, 작업 원칙, 입출력 프로토콜, 팀 통신 프로토콜, 에러 핸들링, 협업, 품질 검증
        - 에이전트 자신이 참조(시스템 프롬프트)

# 본문

- 핵심 역할
    - 범위 결정(무엇을 다루는가)
- 작업 원칙
    - 여러 선택지가 충돌할 때 우선순위 및 판단 기준 제공
- 입출력 프로토콜
    - 다른 에이전트가 이 에이전트의 산출물을 읽을 경로와 형식
- 팀 통신 프로토콜
    - SendMessage Tool로 누구에게/무엇을/언제 전달할지 명시
        - 좋은 메세지 = 발견 사실 + 수신자가 취해야할 행동
    - TeamCreate에서만 유효(서브에이전트X)
- 에러 핸들링
    - 종료조건, 실패 시나리오 별로 해야할 행동과 최대 재시도 횟수
- 협업
    - 이 에이전트가 누구와 어떤 순서로 연결 되는가
- 품질 자체 검증
    - 출력 반환 전 에이전트가 스스로 거쳐야할 체크리스트

# 프론트매터

- 16개 공식 필드있으나 보통 5개 활용
- name, description
    - name = 파일명
    - description 보고 오케스트레이터가 해당 에이전트 언제 호출할지 판단
- model
    - 기본 부모 모델 상속(inherit)
    - 추론 능력 요구사항에 따라 명시
        - haiku(읽기/탐색) → Sonnet(코드리뷰) → Opus(다단계/여러기준 종합, 아키텍쳐 설계 등)
- tools
    - 기본 부모 도구 모두 상속
    - tools 범위 = 부작용 범위 (가드레일 대상)
        - 최소한의 도구/권한만 제공
        - 명시적으로 특정 도구들 제외(disallowedTools)
